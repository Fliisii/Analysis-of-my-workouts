# 🏋️‍♂️ FitLog-Pipeline: ETL & Data Quality для неструктурированных логов

Решение для автоматического сбора, очистки и валидации сырых тренировочных данных. Проект переводит разрозненные текстовые заметки с высокой вариативностью ввода в структурированный, готовый к анализу и визуализации датасет.

**Бизнес-ценность:** Превращение "грязного" человеческого фактора (опечатки, смена языков, пропуски весов) в стабильный аналитический витринный слой (Data Mart) без потери исторических данных.

---

## 🚀 Ключевой функционал

- **Кастомный ETL-парсер (Regex):** Разбор 7+ различных паттернов ручного ввода, включая изменение весов внутри подходов и упражнения с собственным весом.
- **Автоматический аудит (Data Quality Validation):** Многоступенчатый фильтр логических и физических аномалий на этапе инжеста.
- **Умная импутация:** Контекстное восстановление пропущенных метрик на основе структуры тренировочного дня, минимизирующее деструктивное удаление строк (`.dropna()`).
- **Feature Engineering:** Автоматическое снижение кардинальности текстовых признаков (маппинг синонимов) и rule-based классификация упражнений по весовым порогам.

---

## 📊 Матрица валидации и очистки данных (Data Quality)

В пайплайн заложена автоматическая проверка целостности по ключевым метрикам:

| Тип аномалии | Логика детекции / Граничные условия | Метод устранения |
| :--- | :--- | :--- |
| **Физические выбросы** | Повторения >34 или вес >200 кг | Фильтрация выбросов, изоляция аномальных сессий |
| **Логические инверсии** | Перепутанные местами поля веса и повторений | Автоматическая рокировка значений на основе исторических средних |
| **Скрытые дубликаты** | Полные дубли строк по полям `['date', 'exercise', 'weight_kg', 'reps']` | Дедупликация (`drop_duplicates`) для исключения смещения (bias) метрик объема |
| **Синтаксический брак** | Наличие артефактов разметки (*, :) после работы парсера | Дроп некорректных записей с логированием ошибок |
